# Sun Safe Society (React + Vite)

## Run locally
1) Install dependencies: `npm install`
2) Start dev server: `npm run dev`
3) Open the URL printed in the terminal (usually `http://localhost:5173`)

## Build for production / Vercel
- Build locally: `npm run build` (outputs to `dist/`)
- For Vercel: select the repo, framework `Vite`, and use `npm run build` as the build command. Output directory: `dist`.
